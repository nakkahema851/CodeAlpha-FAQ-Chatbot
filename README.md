# 🤖 AI FAQ Chatbot

An AI-powered FAQ Chatbot developed using Python, Streamlit, and RapidFuzz as part of the CodeAlpha Artificial Intelligence Internship.

The chatbot answers frequently asked questions and uses fuzzy matching to understand different ways of asking similar questions.

## ✨ Features

- 🤖 FAQ chatbot interface
- 💬 Answers frequently asked questions
- 🔍 Fuzzy matching using RapidFuzz
- 🧠 Understands different ways of asking questions
- 📚 FAQ knowledge base
- 💻 Python-based application
- 🌐 Streamlit web interface
- 💬 Chat history
- 🗑️ Clear chat option
- ⚠️ Handles unknown questions

## 🛠️ Technologies Used

- Python
- Streamlit
- RapidFuzz
